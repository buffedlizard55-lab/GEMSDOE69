Rank 1: Depth-persistent potential-field edges inside catalogue-derived relay corridors

Layers: training_features band 13 iso_grav, training_features band 14 tmi, derived upward-continuation levels and their directional edge fields.

Signature: Within each already-proposed corridor, track paired edge position, orientation, and signed cross-corridor profile at several upward-continuation heights. Score only edges that remain spatially coherent across height; do not score a scalar maximum or infer depth from one derivative.

Why a catalogue-missing fault: A buried breaching link or fault-bounded basement step can produce a coherent potential-field boundary even where the surface scarp is absent. Persistence is a test of source-scale consistency, not proof that the source is a fault.

Difference / untried audit: The current physics stack uses single-scale Gaussian HG ladders, a tilt proxy, and provided HG/VG fields; the H69-J joint mode takes independent per-layer maxima and combines them with min(). No scorer tracks edge displacement or signed phase across upward-continuation heights. Related prior H69-J was run, but its source (src/gems69/scoring_joint.py) contains only scalar maxima/minima and no upward continuation. Exact proposed persistence statistic is absent from src/gems69 and the reviewed run receipts.

Named mimics: Intrusive or lithologic contacts, regional basement boundaries, and survey-line artifacts may also persist across heights; require tip-derived corridor localization and controls matched for corridor geometry.

Expected HOLDOUT-DTI improvement / cost: Moderate potential, low confidence; qualitative prior only, no numeric score projection.; Medium: FFT/upward continuation, edge tracking across several heights, and a preregistered corridor-level statistic.

Data / validation: Uses pinned gravity/magnetic input bands; no new external data source. The feature cache is absent in this checkout, so inputs are not currently available locally. Test feature alone, then the frozen corridor arm, with whole-segment hide-and-recover, exact visible-fault mask, pooled DTI (alpha 0.2, beta 0.8, 300 m triangular kernel), and the current-best paired CI. No test was run.

Rank 2: Scarp-segment endpoint linkage across tip-derived relay corridors

Layers: lidar_scarp_features_u8: ex_max, step_max, lapneg_max, lappos_max, downface_max, upface_max, cross_max, relief, coh100, strike, valid.

Signature: Extract short, valid scarp segments and their endpoints; test for two-sided, staggered endpoint-to-connector support inside a geometry-proposed relay. The test is topology/termination continuity, not average scarp amplitude or a strike-angle fraction.

Why a catalogue-missing fault: Short breaching scarps can be separated by a gap or be below the line-mapping threshold. Endpoint pairs that face a tip-derived connector could support a missing link without simply extending the mapped fault raster.

Difference / untried audit: Current src/gems69/physics.py reads only ex_max, step_max, downface_max, and valid, then reduces them to one maximum channel. It does not segment lineaments or score endpoints/connectivity. A previous H69-J proposal registered scarp strike coherence; no code path or run receipt implements that statistic. This proposal instead tests segment endpoints and connectivity; it is a distinct, unrun feature test, not a claim that the broader scarp-coherence idea is new.

Named mimics: Pluvial shorelines, road cuts, fan margins, and erosional scarps can create aligned endpoints; require terrain-context vetoes and compare with geometry-matched non-corridor controls.

Expected HOLDOUT-DTI improvement / cost: Low-to-moderate potential, low confidence; qualitative prior only, no numeric score projection.; High: robust line extraction, endpoint uncertainty, topology checks, and mimic controls.

Data / validation: Uses the pinned LiDAR descriptor stack; no new external data source. The feature cache is absent in this checkout. Freeze the extractor before any holdout scoring; test this feature alone for AUC leakage, then evaluate the unchanged corridor proposal/placement pipeline. No test was run.

Source limit: Relay-ramp breaching geometry is described in Giddens & Faulds (source register, previously verified); the endpoint-specific LiDAR signature is a new hypothesis and is not established by that citation.
