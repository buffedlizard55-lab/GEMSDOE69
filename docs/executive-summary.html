Executive summary — exactly how to submit

  1. Only if the banner is green. The banner is computed by scripts/release_gate.py from hash-bound evidence: holdout gate, current-best comparison, leakage canary, uniqueness (surface and dots), validator and method manifest.
  2. File. Single-band GeoTIFF .tif, or a .zip containing exactly one GeoTIFF. Use the -zeros variant: float32, EPSG:32611, 3730×3292, transform (100, 0, 243350, 0, −100, 4508550), every value finite in [0,1].
  3. Upload. Competition 306 → Submissions → choose the file → add a unique note of at most 140 characters (e.g. relay-ramp corridors, k=12k dots).
  4. One final choice. Per the problem page, competitors pick a single submission for both prize rounds; the Final round rescores against labels revised after expert review of all submissions.
