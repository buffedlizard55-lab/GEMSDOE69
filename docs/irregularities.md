## 2. Historical Repository Code Bugs Discovered & Fixed (`Pass 1 & Pass 2`)

| ID | File & Line (`7b93b40`) | Verified Bug | Root-Cause Fix & Unit Test |
| :--- | :--- | :--- | :--- |
| **`IR-69-CODE-01`** | `src/gems69/corridors.py` (`_tip_window_interval`) | Projected strand A and strand B onto along-strike coordinates using **two independent origins** `(xs_a[0], ys_a[0])` and `(xs_b[0], ys_b[0])`, forcing `a_min == b_min == 0` so along-strike interval separation was identically `0.0` for every pair in the dataset. | Fixed to project both strands relative to a single shared midpoint origin `(mx, my)`; verified in `tests/test_geodesic.py::test_common_origin_separation_bugfix_ir69_code01`. |
| **`IR-69-CODE-02`** | `src/gems69/corridors.py` (`_priority`) | Ranked candidate step-overs by `-abs(w_px - 28.0)`, truncating all `1,200` retained corridors in `PR #6` into an artificial `2.77–2.83 km` band despite the Giddens & Faulds (2025) `0.1–15 km` rule. | Replaced with multi-partner physical width weighting across the full `W = 0.1–15.0 km`, `L <= 3.5W` domain. |
