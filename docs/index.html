How to submit (summary)

Full steps are on the executive summary. In short: a single-band float32 GeoTIFF on the official grid (EPSG:32611, 100 m, same bounds as the training file), values in [0, 1], NaN only outside the footprint, a unique name, and a note of 140 characters or fewer. The organizer's format rules are in the official competition page (S01).

What we checked about the 0.2778 claim

0.2778 is not the top score. On the official public board (read 2026-10-12), #1 is 0.4275 and 0.2778 is rank #24. The board shows usernames, not files, so the 0.2778 figure cannot be linked to the GEMSDOE32 file h33-h33-2-b2…-zeros. That repository calls the same file UNSCORED.

Read the full analysis: 0.2778-analysis.md · leaderboard check

Why a sparse file can score well — from the metric alone. Because TPw + FNw equals the number of truth pixels |G| (a fixed number), the metric is DTI = T / (0.2·T + 0.2·FP + 0.8·|G|). A dot should be added only if Δt·(D − 0.2·T) > 0.2·T·(1 − m). At DTI 0.2778, a dot must add about 6% of its false-positive cost in expected truth coverage. The rule is implemented and tested (src/gems/metric.py).
