What this project does

Candidate corridors are scored with gravity/magnetic gradients and tilt, magnetic lows, LiDAR scarp evidence, and orientation priors; the current transfer-only candidate is not eligible. Strike is not dip, and dextral/releasing sense is not measured by a raster-only catalogue.
