## Tools and local checks
- `src/gems/metric.py` implements S01's definitions; `tests/test_metric.py` checks it against a brute-force transcription (25 tests pass; see docs/session-log.md).
- `src/gems/validate_submission.py` checks the S01 format rules. It does not know the official footprint (IR-07).
- Python 3.11, numpy 2.4.6, rasterio 1.4.4 (GDAL 3.10.3), pytest, installed from PyPI (allowed host).
