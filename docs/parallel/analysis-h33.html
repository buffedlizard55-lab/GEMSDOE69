SCORE ATTRIBUTION · EVIDENCE AUDIT

What the H33 evidence does—and does not—show

The key issue is file attribution. The public value cited in the prompt exists on the participant-level leaderboard, but evidence reviewed here does not connect it to the named H33-2-B2 GeoTIFF.

Conclusion: the reason the named H33 file “scored” the cited value cannot be established.

The public leaderboard is participant-level; the GEMSDOE32 owner page labels its H33 file “UNSCORED” and describes its own projected value as a model, not a score. No organizer submission receipt mapping the exact TIFF/hash to a score was found in this checkout or on the reviewed page.

Evidence chain

  1. User-supplied association: the prompt pairs a particular H33-2-B2 filename with a public value. That is a claim to audit, not a submission receipt.
  2. Owner site: the GEMSDOE32 landing page offers an H33 TIFF but explicitly labels it UNSCORED. It calls its own quoted model value a projection, not a competition score. The page's local metrics are owner-reported, not organizer-confirmed.
  3. Owner sidecar: the audit JSON is owner-generated metadata. A field such as slot_decision can report the owner's local decision; it is not an organizer score receipt. The TIFF bytes were not downloaded or independently re-read in this session.
  4. Official leaderboard: during the requested review, the live page showed the cited public value on a participant-level row. The page did not identify the H33 filename or hash and did not supply a receipt linking that row to the file. The participant row and full table are not reproduced here.
  5. Current-leader claim: the official live page had a leader above the user's stated reference value. That reference is no longer the current top as checked. The leaderboard changes over time; use the live organizer site rather than a stale copied value.

Open the official competition and navigate to its live leaderboard. This project does not copy or poll the table.

What the competition metric can explain in general

The official metric is a distance-weighted Tversky index. It applies a triangular distance kernel with 300 m support and weights false-positive and false-negative terms with the competition's stated alpha and beta. Predictions close to hidden expert-labeled fault cells receive more true-positive credit than equally confident distant predictions; prediction mass far from hidden faults adds false-positive cost. That describes the metric, not the named file's performance.

The GEMS test faults are newly expert-mapped faults omitted from the existing public USGS fault database. A visible-catalogue hide-and-recover holdout can test spatial transfer, but it is not the private ground truth and cannot retrospectively explain a public submission score.

Could this project beat the cited value?

It is scientifically possible for a new method to perform better, but no evidence in this checkout supports a score forecast. The corridor hypothesis is directly motivated by the regional structural literature; it must still pass the paired spatial holdout against the same pipeline without corridor priors, survive feature-by-feature leakage checks, and pass the registry uniqueness and format gates.

Because the H33 file-to-score link is not established, “beat the cited value” is not a valid file-level benchmark. The correct benchmark is the current official leaderboard plus the paired local holdout, with the two kept in separate evidence classes. No slot is used and no score projection is reported.

Irregularities and limits for review

  • Attribution gap: no organizer receipt ties the user-named TIFF/hash to the public leaderboard row.
  • Evidence-class gap: owner-reported local holdout or model projections are not public leaderboard scores and not organizer receipts.
  • File-access gap: this checkout contains neither the TIFF nor the original failed upload, so hashes, pixels, dots, and prior-raster uniqueness thresholds cannot be checked.
  • Live-data limitation: the published DrivenData Terms of Use prohibit monitoring/copying without prior written consent; this project links to the official competition homepage and does not mirror the live board.
