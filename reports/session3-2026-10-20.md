* **H69-M coverage collapse.** A global evidence ranking concentrates corridors in a few
  high-gradient provinces. In the NE fold of both draws H69-M placed 103–208 dots (other arms
  10k–40k) and scored 0.0000 there. That is a design defect, not an evaluator bug; H69-N was built to fix it.

  instrument (transfer_ref beats control by +0.0343 [0.0228, 0.0462] detached). Evidence
  ranking pulls toward pull-aparts (1,130–1,134 of 1,200), which is the wrong population for
  recovery here.
* **Leakage canary:** worst single-feature/propensity AUC 0.694 (H69-M run), far below 0.90.

## 4. Why h33-h33-2-b2 scored 0.2778 (USER-REPORTED) and can a unique lane raster beat it?

**Provenance caveat (added on merge with main):** a parallel session's owner-source audit
(`reports/h33-owner-source-audit-2026-10-20.md`) found that GEMSDOE32's own audit JSON marks the
exact h33-2-b2 file `UNSCORED`, records 0.2747 as a *projection*, names a 0.2708 file as the
already-scored fallback, and has `receipt: null`. So "this file scored 0.2778" cannot be
established; main's `docs/research/why-0278.md` is now a superseding note and the session-3 causal
text survives only in Git history (commit 3bacb9e).

What is measured here, whatever the score linkage: the bytes are 37,654 unit dots, none on the
catalogue, median 1.97 km away, 5.77 % within 300 m. Under the pooled metric a dot field gains
when each added dot's hit rate k > 0.2·DTI. That is why sparse, off-catalogue, high-precision dot
fields beat dense ribbons. Holdout DTI values here (~0.03–0.05) are **not** comparable to any
leaderboard figure. The lane's best holdout arm is a dot-overlap duplicate (IR-69-REG-03), and
neither unique session-3 candidate beats it. Whether a unique lane raster beats 0.2778 live is
unknown.
